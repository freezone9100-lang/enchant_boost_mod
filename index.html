Process

Three steps, no build toolchain

01

Point it at your install

The script auto-detects your newest installed Minecraft version, or you can pass --version / --jar directly. It reads the real enchantment JSON out of that exact jar.

02

Edit the level table

Open the script and adjust the ENCHANT_BOOSTS dictionary — enchantment id to new max level. Everything else in the original data (costs, formulas, requirements) is left untouched.

03

Build and drop it in

Run python3 build_enchant_boost_mod.py. It outputs a ready Fabric .jar — copy it into your .minecraft/mods folder and launch the Fabric profile.

Know before you boost

Not every enchant scales forever

Protection-type enchantments are capped at 80% total damage reduction, calculated across your whole armor set — pushing past that with higher levels stacks no further benefit. Damage-dealing enchantments like Sharpness have no such ceiling and scale linearly with level.
